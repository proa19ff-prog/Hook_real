# Changelog

Все заметные изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Added
- Встроенный резолвер-сервер: адрес включён в сборку по умолчанию — полные
  записи YouTube, недоступные напрямую, играют сразу после установки. В
  настройках («Резолвер-сервер») можно указать свой сервер или отключить
  источник.
- Онбординг при первом запуске: выбор языка из 20 языков интерфейса и экран про
  MicroG (что это, когда нужен, статус на устройстве, ссылка на официальный
  релиз). Пропускается одним нажатием, выбор сохраняется на устройстве.
- 20 языков интерфейса: en, ru, es, pt, fr, de, it, tr, pl, uk, ar, hi, bn, id,
  zh, ja, ko, vi, th, nl (включая RTL для арабского).
- Опциональный источник «Сервер»: само-хостинг резолвера полных аудиопотоков.
  Контракт и эталонная реализация — `docs/REMOTE_RESOLVER.md`; адрес сервера
  задаётся в настройках, без него источник неактивен.
- Диагностический инструмент `tool/youtube_client_probe.dart`: проверка каждого
  внутреннего клиента YouTube отдельно (манифест, битрейт, реальный GET-запрос).
- Релизная обвязка: LICENSE (MIT), CI (analyze + test), шаблон issue,
  CHANGELOG, adaptive-иконка, runtime-запрос `POST_NOTIFICATIONS`.

### Changed
- Воспроизведение YouTube больше не привязано к одному внутреннему клиенту:
  резолвинг идёт по цепочке клиентов (`ios → tv → mweb → androidVr → safari →
  androidSdkless`) с реальной проверкой потока и запоминанием рабочего клиента.
  Ранее использовался только `androidSdkless`, который теперь на многих сетях
  зависает или получает HTTP 403.
- User-Agent запросов к CDN теперь всегда совпадает с клиентом, выпустившим
  ссылку (раньше всем ссылкам навязывался Android User-Agent — часть ссылок
  отбивалась ошибкой 403).
- Таймауты: жёсткий лимит 7 с на каждого клиента, общий бюджет резолва поднят
  до 20 с; запрос уведомлений Android 13+ выполняется при старте.

### Removed
- Мёртвый код (`glass_card.dart`), неиспользуемая web-платформа, зависимость
  androidx.multidex (не нужна при minSdk 21).

### Security
- `usesCleartextTraffic` выключен — весь трафик идёт по HTTPS.
- Данные приложения исключены из облачного бэкапа и переноса на новое
  устройство (библиотека сознательно живёт локально).
- Включены R8 + сжатие ресурсов для релизной сборки.
