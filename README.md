# Hook

![Логотип Hook](hook.jpg)

**Hook** — экспериментальный Android-плеер на Flutter для поиска и воспроизведения музыки из сетевых источников. Он объединяет каталог, очередь, локальную медиатеку, тексты песен, рекомендации и настраиваемый визуальный стиль.

> Проект зависит от внешних сервисов. Поиск, обложки, тексты и воспроизведение могут быть недоступны из-за сети, региона, авторских прав или изменений на стороне провайдеров.

## Возможности

### Поиск и воспроизведение

- Поиск по каталогу, SoundCloud, публичным записям YouTube и Audius; по умолчанию выбраны все источники.
- Поиск по словам песни в отдельном режиме **«По тексту»**: поиск по содержимому текстов NetEase с фрагментом совпадения, а не переименованный поиск по названию.
- Русское написание иностранных имён (например, `Мартин роз` → `Martin Rose`), общая транслитерация, исправление раскладки и неточные запросы.
- Подбор аудио по исполнителю, версии и длительности; отбрасывание превью, каверов и ремиксов, если они не запрошены. Независимые источники подбирают доступную запись параллельно.
- Мини-плеер и полноэкранный плеер: пауза, перемотка, следующий и предыдущий трек, очередь, shuffle, repeat, скорость и высота тона.
- Фоновое воспроизведение на Android, экран блокировки и уведомление в шторке.
- Управление из уведомления: предыдущий трек, play/pause, следующий трек и добавление/удаление текущего трека из избранного.
- Автопауза при отключении наушников.

### Медиатека и рекомендации

- Локально сохраняемые избранное, история и пользовательские плейлисты.
- Импорт Spotify-ссылок, списков `Артист — Трек` и CSV-файлов.
- «Волна» — автоматически дополняемая очередь похожих треков с исключением уже прослушанного.
- Экран кэша аудиофайлов с просмотром размера и очисткой.

### Тексты и оформление

- Три сохраняемых режима текста: **Строки**, пословное **Караоке** и крупный **Фокус**; выбор из плеера с Lottie-превью.
- Переход по строкам и сохраняемая коррекция сдвига отдельно для каждой записи, в том числе для построчных текстов.
- Без временных меток текст остаётся статичным. Без настоящих пословных меток выделение слов приблизительное.
- Обновлённый экран поиска, подписи источников и реальный источник аудио в заголовке плеера; поддержка уменьшения анимаций.
- Встроенные темы, импорт и экспорт JSON-тем.
- GLSL mesh-gradient, vinyl-noise, blur и палитра, основанная на обложке текущего трека.

## Источники музыки

- **SoundCloud** — полные незашифрованные аудиопотоки; Go+/preview и закрытые записи не подменяют полную песню.
- **YouTube** — публичные аудиопотоки через `youtube_explode_dart`. Прямой доступ без стороннего downloader-сервера. Доступность зависит от региона, сети и изменений YouTube; защищённые/недоступные записи могут не воспроизводиться.
- **Audius** — публичные записи преимущественно независимых исполнителей. Платные, gated и недоступные потоки исключаются, доступ повторно проверяется перед запуском.
- **Каталог** — метаданные iTunes Search. В сохранённых данных внутренний ключ `spotify` оставлен ради совместимости; в интерфейсе он подписан «Каталог», поскольку это **не Spotify-аудио**. Подходящая полная запись ищется среди доступных источников. Само присутствие в каталоге не гарантирует воспроизведение.
- **Spotify-ссылки** — импорт метаданных плейлистов, альбомов и отдельных треков.
- **NetEase** — поиск по словам и источник синхронизации текста, а не дополнительный аудиопоток.

Официальные API Spotify и Apple Music не выдают приложению произвольные полные аудиопотоки без авторизации и своих SDK/подписок. Hook не обходит DRM или оплату и не использует закрытый API Liner. Совпадение метаданных и длительности снижает вероятность неправильной версии, но не доказывает идентичность самой фонограммы. Гарантии «вся музыка» нет.

## Требования

- Flutter SDK `>=3.47.0` с Dart `>=3.13.0 <4.0.0` (требования текущего Lottie-пакета).
- Android SDK с `compileSdk 36`.
- Java 17.
- Android-устройство или эмулятор.
- Интернет для сетевых функций.

## Быстрый старт

```bash
flutter pub get
flutter devices
flutter run
```

Для конкретного устройства:

```bash
flutter run -d <device-id>
```

Проверки:

```bash
flutter analyze
flutter test
```

Отдельная необязательная сетевая диагностика новых источников и записи Sunflower около 2:38:

```bash
dart run tool/source_smoke.dart
```

Она выводит найденные записи, доступность потока и ответ CDN на небольшой range-запрос. Это не тест фактического декодирования на Android. Основной набор тестов использует подменённые HTTP-клиенты и не зависит от доступности внешних сервисов.

Сборка Android-артефактов с собственной signing-конфигурацией:

```bash
flutter build apk --release
flutter build appbundle --release
```

## Использование

1. Откройте вкладку поиска и введите название трека, альбома или исполнителя.
2. Нажмите трек, чтобы создать очередь и начать воспроизведение.
3. Откройте полноэкранный плеер для текстов, очереди, волны и параметров воспроизведения.
4. Используйте кнопку сердца в плеере либо в развёрнутом уведомлении, чтобы изменить избранное.
5. В медиатеке импортируйте Spotify-ссылку, список треков или CSV, затем слушайте либо сохраните коллекцию в плейлист.

## Ограничения

- Нет аккаунтов, серверной части и синхронизации между устройствами.
- Доступность SoundCloud, YouTube, Audius, Spotify embed, каталогов и сервисов текстов зависит от сети, региона и изменений внешних сервисов. Audius может отвечать 403 на уровне защиты сети, а YouTube — не отдавать пригодный поток.
- Каталожная запись может не найти точную полную версию ни в одном доступном источнике. В этом случае плеер сообщает об ошибке, а не запускает 30-секундный фрагмент или произвольный кавер.
- Поиск по словам зависит от индекса NetEase: не все тексты присутствуют, а одна фраза может встречаться и в оригинале, и в каверах.
- Karaoke-режим доступен только для треков, которым внешний сервис вернул текст; построчная и пословная синхронизация зависит от конкретной записи.
- Основная конфигурация репозитория предназначена для Android. Поддержка web и iOS не заявляется.
- В репозитории нет лицензии.

## Структура проекта

- `lib/features/audio_player/` — воспроизведение, очередь, уведомление и экраны плеера.
- `lib/features/extractor/` — каталог, независимые источники SoundCloud/YouTube/Audius и подбор полных потоков.
- `lib/features/search/` — поиск по названию и словам, нормализация и варианты русско-английских запросов.
- `lib/features/library/` — избранное, история, плейлисты и кэш.
- `lib/features/import/` — импорт Spotify, списка и CSV.
- `lib/features/lyrics/` — поиск, разбор и отображение текстов.
- `lib/features/recommendations/` — логика волны.
- `lib/features/theme_engine/` и `assets/` — темы, изображения и GLSL-шейдеры.
- `test/` — unit- и widget-тесты.
